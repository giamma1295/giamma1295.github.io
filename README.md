# Gianmaria Scorza | Personal Website

This repository hosts the personal website of **Gianmaria Scorza**, a Backend Engineer.  
The site is a modern, responsive, multilingual (Italian / English) “About Me” page optimized for desktop and mobile devices.

---

## 📌 Features

- **Hero Section** with name, subtitle, and animated buttons (GitHub, LinkedIn, Email)
- **Multilingual**: Italian / English with user preference saved
- **Sections**: About, Tech Stack, and Contact
- **Responsive Design**: optimized for desktop, tablet, and mobile
- **Animations**: fade-in sections and bouncing email button
- **SEO & Social Sharing**: OpenGraph and Twitter Card multilingual
- **Performance**: lazy-loaded images, optimized SVGs/FontAwesome icons

---

## 🛠 Technologies Used

- **HTML5 & CSS3**
- **Tailwind CSS** for responsive layout and modern styling
- **JavaScript** for multilingual support and animations
- **FontAwesome** for button icons
- **GitHub Pages** for static site hosting
